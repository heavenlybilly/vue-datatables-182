# Публичный контракт `API` 2.0

Контракт описывает поддерживаемые возможности, форматы пакета и правила работы
публичных компонентов. Он относится к `API 2.0`, реализуемому в текущем
репозитории. Номер в `package.json` пока равен `1.3.0-alpha.0`.

## Навигация

- [Таблица `DataTable`](data-table.md): параметры, слоты, события и методы.
- [Колонка `DataTableColumn`](data-table-column.md): значения, ключи и закрепление.
- [Состояние](api-v2/state.md): владение значениями, нормализация и переходы.
- [Удалённые данные](api-v2/remote.md): запросы, ответы и адаптеры.
- [Типизация](typed-table.md): фабрика `createTypedTable<T>()`.
- [Оформление](customization.md): `CSS`-переменные и замена элементов интерфейса.
- [Миграция](migration-guide.md): обновление с `1.x`.

## Совместимость

| Область             | Требования                                                                                                  |
| ------------------- | ----------------------------------------------------------------------------------------------------------- |
| `Vue`               | `^3.5.0`; проверяются минимальная `3.5.0` и текущая версия диапазона                                        |
| `Vue 2`             | Не поддерживается; приложения остаются на `1.x` до миграции                                                 |
| Браузеры            | `Firefox 84.0+`; две последние стабильные версии `Chrome`, `Edge` и `Safari`, включая `Safari` на `iOS`     |
| Устаревшие браузеры | `Internet Explorer` и версии вне матрицы не поддерживаются                                                  |
| Сборщики            | `ESM`, `Vite` и `Webpack 5` с обработкой `Vue`-компонентов и `CSS`                                          |
| Среда разработки    | `Node.js 22.12+` или `24`; `TypeScript 5.5+`                                                                |
| Серверный рендеринг | Импорт, рендеринг локальных строк и последующая гидратация; удалённая загрузка после подключения в браузере |
| `JavaScript`        | Только `ESM`; `CJS` и `UMD` не входят в контракт                                                            |
| Стили               | Отдельный импорт `vue-datatables-182/dist/index.css`                                                        |

Матрица определяет условия поддержки, а не подтверждает уже выполненные проверки.
Перед выпуском отдельно проверяются `Firefox 84.0` и актуальный `Firefox`.
Параметры сборки преобразуют синтаксис `JavaScript` и часть `CSS`, но не добавляют
полифиллы браузерных `API`. Ручной порядок проверки описан в [Storybook](storybook.md).

## Подключение и конфигурация

`DataTable` и `DataTableColumn` работают при прямом импорте без установки плагина.
Вызов `app.use(VueDatatables182, options)` задаёт общую конфигурацию приложения.
Установка без `options` допустима: используются значения по умолчанию.

| Параметр плагина   | Тип                      | Значение по умолчанию                     |
| ------------------ | ------------------------ | ----------------------------------------- |
| `messages`         | `Partial<TableMessages>` | `defaultMessages`                         |
| `registerGlobally` | `boolean`                | `false`                                   |
| `csrfToken`        | `string`                 | `undefined`                               |
| `requestAdapter`   | `RequestAdapter`         | стандартный адаптер `JSON`-запроса `POST` |
| `responseAdapter`  | `ResponseAdapter`        | стандартный адаптер `JSON`-ответа         |

Глобальная регистрация при `registerGlobally=true` выполняется синхронно.
Приоритет настроек: параметр таблицы → конфигурация приложения → стандартное значение.
Настройки не хранятся в общем изменяемом объекте модуля. Приложения и отдельные
запросы серверного рендеринга не разделяют конфигурацию.

## Экспортируемые компоненты и значения

Из корня пакета доступны:

- `DataTable`, `DataTableColumn`, `VueDatatables182`.
- `createTypedTable<T>()`.
- `Source`, `SortDirection`, `TextAlign`, `Sticky` — константы строковых значений.
- `defaultMessages`, `defaultRequestAdapter`, `defaultResponseAdapter`.

Типы экспортируются из того же пути:

| Группа                    | Типы                                                                                                                        |
| ------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| Таблица                   | `DataTableProps<T>`, `DataTableSlots`, `DataTableEmits<T>`, `Sort`                                                          |
| Колонка                   | `DataTableColumnProps`, `DataTableColumnSlots<T>`, `CellSlotProps<T>`, `HeaderSlotProps`                                    |
| Элементы управления       | `ToolbarSlotProps`, `SearchSlotProps`, `PaginationSlotProps`, `RowsPerPageSlotProps`                                        |
| Типизированные компоненты | `TypedTable<T>`, `TypedDataTable<T>`, `TypedDataTableColumn<T>`                                                             |
| Записи                    | `RowItem`, `RowValue`, `RowKey`, `RowKeySelector<T>`                                                                        |
| Сообщения и плагин        | `TableMessages`, `PageDetailsContext`, `PluginOptions`                                                                      |
| Удалённые данные          | `TableFilter`, `RequestContext`, `BuiltRequest`, `RequestAdapter`, `BuiltResponse<T>`, `ResponseAdapter<T>`, `TableData<T>` |
| События запросов          | `RequestStartPayload`, `RequestSuccessPayload<T>`, `RequestErrorPayload`, `RequestEndPayload`                               |
| События строк             | `RowClickPayload<T>`, `SelectionChangePayload<T>`                                                                           |
| Значения констант         | `Source`, `SortDirection`, `TextAlign`, `Sticky` также доступны как типы                                                    |

Внутренние модули состояния, обработки, отображения и реестра колонок не являются
публичным `API`. Их прямой импорт не поддерживается. Старые типы с префиксом `DT`
не сохранены. Декларации формируются из исходных компонентов и публичных типов.

## Тип строки и ссылка на компонент

`createTypedTable<T>()` возвращает исходные компоненты с типизированными
`items`, `rowKey`, `responseAdapter`, `value`, полем `item` слота `cell` и событиями строк.
Дополнительные компоненты-обёртки во время выполнения не создаются.

При обычном импорте используется общий `RowItem`: словарь со значениями `any`.
Тип строки слота не выводится автоматически из массива `items`.
Обычный параметр `value` принимает `unknown`.

Ссылка на компонент типизируется через `InstanceType<typeof DataTable>`.
Доступны `reload()` и `clearSelection()`. Отдельного типа `DataTableMethods` нет.
Типизация не заменяет проверку `JSON` во время выполнения: `responseAdapter`
получает `unknown` и отвечает за проверку пользовательской структуры записи.

## Оформление и расширение интерфейса

[CSS-контракт](customization.md) определяет переменные оформления и стабильные классы.
`density` выбирает плотность. Слоты `search`, `rowsPerPage` и `pagination`
позволяют подключить элементы управления приложения с готовыми обработчиками.
Верхняя панель получает сведения о выборе и загрузке.

Слот `header` заменяет содержимое заголовка, но сохраняет отдельную кнопку
сортировки. `textOverflow` и `headerTextOverflow` управляют переносом текста.

## Границы версии 2.0

Поддерживаются локальные и удалённые данные, одна активная сортировка,
выбор текущей страницы, реактивные декларативные колонки, закрепление,
локализация и пользовательские состояния данных.

В объём версии не входят выбор между страницами, множественная сортировка,
виртуализация, экспорт, редактирование, группировка, перестановка колонок
перетаскиванием и встроенный поллинг. Поддержка этих возможностей требует
отдельного расширения контракта.

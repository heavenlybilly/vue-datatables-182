# `Storybook` и проверка в браузере

`Storybook` содержит интерактивные примеры таблицы. Они позволяют проверить
интерфейс, загрузку, управление состоянием и оформление независимо от приложения.
Для удалённых данных используется имитация сервера через `MSW`; отдельный сервер `API` не требуется.

## Запуск

```sh
npm ci
npm run storybook
```

Адрес по умолчанию: `http://localhost:6006`. При занятом порте выбирается другой
порт. Каталог содержит `47` сценариев: локальные и удалённые данные, пагинацию,
выбор строк, состояния, динамические колонки, закрепление, клавиатуру,
локализацию, оформление и производительность.

`npm run build:storybook` создаёт статический каталог `storybook-static`.
Он открывается через `HTTP`-сервер: рабочему процессу `MSW` требуется подходящий
контекст браузера. Открытие `HTML` напрямую через файловый адрес не заменяет `HTTP`.

`npm run check:package` проверяет установленный архив, примеры, сборку и серверный
рендеринг. Эта команда не запускает сервер просмотра.

## Демонстрация загрузки ячеек

Сценарий «Удалённые данные → Загрузка и отмена устаревших запросов»
использует задержку ответа `2,5 секунды`.

1. После открытия ожидается появление записей.
2. Изменяется поисковая строка или страница.
3. Во время нового запроса содержимое ячеек скрывается и заменяется полосами загрузки.
4. После ответа показываются новые данные с сохранением геометрии до обновления.

Сценарий «Пользовательская загрузка» отличается: задан слот `loading`, поэтому
вся область строк заменяется его содержимым.

## Автоматические проверки взаимодействия

Некоторые сценарии содержат функцию `play`, которая выполняет действия и
проверяет результат. В интерфейсе используется панель `Interactions`;
успешный результат обозначается `Pass`. Повторный запуск сценария восстанавливает
начальные значения и выполняет действия заново.

| Группа                  | Что проверяется                                                              |
| ----------------------- | ---------------------------------------------------------------------------- |
| Интеграция              | Обновление записей и колонок без пересоздания таблицы                        |
| Доступность             | Фокус, `Enter` для сортировки и страницы, `Space` для флажка                 |
| Прокрутка и закрепление | Прокрутка по обеим осям и сохранение закреплённых позиций                    |
| Оформление              | Отдельная кнопка сортировки, выбор, темы, узкий контейнер и внешние элементы |
| Основные сценарии       | Очистка поиска из состояния `noResults` и восстановление записей             |

`CI` на `Node.js 22` и `24` выполняет сценарии в `Chromium` без видимого окна.
Локальный запуск:

```sh
npx playwright install chromium
npm run test:storybook
```

Команда запускает браузерный сервер тестов самостоятельно. Предварительный
запуск `npm run storybook` не требуется. Сборка каталога сама по себе не
выполняет функции `play`.

## Ручная проверка совместимости

`Firefox 84.0` и актуальный `Firefox` проверяются отдельно. Проверки `Chromium`
не подтверждают работу минимальной версии `Firefox`. Остальные браузеры
определяются [матрицей совместимости](api-v2.md#совместимость).

Если оболочка `Storybook` не работает в `Firefox 84`, проверяется производственная
сборка отдельного приложения с установленным пакетом. Совместимость каталога
разработки и самой библиотеки оценивается раздельно.

### Данные и состояние

- Локально отображаются значения, работают поиск, его очистка и сортировка.
- Доступны первая, последняя и единственная страницы; изменение размера сбрасывает страницу.
- Управляемые значения меняются после подтверждения родителем.
- Выбор одной строки, всех видимых строк и частичный выбор соответствуют лимиту.
- Смена страницы и удаление выбранной записи корректно обновляют выбор.
- Для удалённых данных проверяются первая загрузка, повторная загрузка ячеек,
  ошибка, повтор, пустой источник и отсутствие результатов.
- Новый поиск до завершения ответа показывает только актуальный результат.
- Очистка из `noResults` восстанавливает данные и пустое значение поиска.

### Колонки и прокрутка

- Изменения `title`, `width`, `sticky` и `v-if` применяются без пересоздания таблицы.
- Заголовок закрепляется в ограниченном контейнере.
- Колонки слева и справа сохраняют позиции при прокрутке по обеим осям.
- Длинное слово и многострочный текст не расширяют внешний контейнер.
- При ширине `320px` панели переносятся, прокрутка ограничена областью таблицы.
- Закреплённые группы оставляют место обычным колонкам.

### Клавиатура и оформление

- `Tab` проходит по элементам, `Enter` активирует кнопки, `Space` переключает флажки.
- Фокус сортировки виден и не обрезан. Текст заголовка не сортирует по клику.
- Поле поиска меняет цвет границы при фокусе без `outline`; наведение не меняет ширину.
- Кнопка действия строки становится видимой при фокусе.
- Изменение сообщений отражается в подписях; пустой диапазон равен `0–0`.
- Увеличенный текст не скрывает элементы управления.
- В светлой и тёмной темах читаются сообщения, подсказки, недоступные кнопки и ошибки.
- Выбранные закреплённые ячейки имеют тот же фон, что остальные ячейки строки.
- Переменные темы работают на корне и на родителе.
- При `prefers-reduced-motion` полосы загрузки не анимируются.
- В режиме принудительных цветов флажок остаётся различимым.

### Производительность

Сценарии производительности сравнивают `1000`, `10 000` и `50 000` записей
с пагинацией. Демонстрация без пагинации ограничена `1000` строками.
Это измерения для конкретных данных, а не гарантированные пределы пакета.

## Фиксация результата

Для обнаруженной проблемы фиксируются название сценария, версия браузера,
шаги воспроизведения, ожидаемый и фактический результат, а также ссылка
на исправление или задачу. Успешная сборка не заменяет такой отчёт.

| Браузер               | Версия           | Данные и состояния | Выбор и клавиатура | Закрепление и прокрутка | Итог    |
| --------------------- | ---------------- | ------------------ | ------------------ | ----------------------- | ------- |
| Минимальный `Firefox` | `84.0`           | Не проверено       | Не проверено       | Не проверено            | Открыто |
| Актуальный `Firefox`  | Не зафиксирована | Не проверено       | Не проверено       | Не проверено            | Открыто |

Результаты ручных проверок не заполнены. Их подтверждение остаётся условием выпуска.
